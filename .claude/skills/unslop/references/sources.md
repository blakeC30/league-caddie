# Sources

Research behind the `unslop` skill. Read 2026-08-14.

| # | Source | What it contributed |
|---|---|---|
| 1 | [AI Slop Design: Why AI-Generated UI Looks Generic (Fix Guide 2026)](https://vibecodekit.dev/ai-slop-design) | The six rules — commit to one aesthetic in a DESIGN.md, cap the palette at three hues, real font pairings, borderless-by-default cards, 8pt grid, APCA contrast. Source of the separation ladder and the pre-ship checklist. |
| 2 | [Unslop UI: Kill the AI Design Tells](https://www.claudecodehq.com/playbooks/unslop-ui) | The 13 priority-ordered tells with grep-able code signatures and complaint-frequency data. Source of the tell table, the `FILE:LINE \| TELL \| SEV` report format, the "tasteful default" (cream + serif + sage) tell, and the principle that a tell is an unspecified default rather than a banned value. Also lists what *not* to chase (bento grids, dark mode itself). |
| 3 | [AI Slop Fonts and Gradients: The Tells That Give Away AI Design](https://www.925studios.co/blog/ai-slop-design-tells) | The four headline tells (Inter, indigo→purple gradient, three rounded cards, weightless copy + interchangeable thin-line icons) and the framing that AI should be an executor of decisions, not the taste-maker. |
| 4 | [AI Slop Web Design: Complete Guide to Spotting and Fixing](https://www.925studios.co/blog/ai-slop-web-design-guide) | Semantic color systems over decorative gradients; real product imagery over stock; purposeful motion; copy in the founder's voice. Source of the "common mistakes when fixing slop" — over-designing to compensate, fixing visuals without fixing content, treating it as one-time. |
| 5 | [Why Your AI Keeps Building the Same Purple Gradient Website](https://prg.sh/ramblings/Why-Your-AI-Keeps-Building-the-Same-Purple-Gradient-Website) | The mechanism: `bg-indigo-500` was a Tailwind default, thousands copied it, models learned "modern = purple." Output is the median of tutorials scraped 2019–2024. Source of the explicit-prohibitions technique and the cultural-reference technique. |
| 6 | [How to Avoid AI Slop When Using Claude Design (The Design System Approach)](https://www.mindstudio.ai/blog/claude-design-avoid-ai-slop-design-system) | The DESIGN.md section structure, exact hex / exact font name / pixel measurement precision, "silence in your design system = defaults", test-on-one-component-first, and keeping a changelog. |
| 7 | [AI in UI Design: Avoiding "AI Slop" and Shipping Faster](https://www.managed-code.com/blog-post/ai-slop-in-design) | The product-UI angle: slop looks fine statically and unravels under real content and multiplying states. Source of the missing-states tell, the 3–5 named elevation levels, and the measurable pre-handoff gate (token coverage, ≤3 shadow recipes, contrast, state completeness). |
| 8 | [Hallmark: Stop AI-Generated UI Slop in One Command](https://dev.to/rams901/hallmark-stop-ai-generated-ui-slop-in-one-command-in-2026-3p9n) | Skill architecture: four verbs (build/audit/redesign/study), validation gates run before emission, `SKILL.md` + `references/` as behavioral instruction rather than a code library. Source of this skill's verb structure. |
| 9 | [The Anti-AI-Slop Design Skill: How Hallmark Fixes Generic AI UI](https://rohitraj.tech/hi/notes/anti-ai-slop-design-skill-hallmark-guide-2026) | Gates as "unit tests for taste"; pre-emission self-critique; themes must change macrostructure, not just repaint the palette. |
| 10 | [Avoiding AI Slop in Frontend Design with Vibe Coding](https://saascity.io/blog/stunning-frontend-designs-vibe-coding-avoid-ai-slop) | Prompt patterns: ban generic choices explicitly, specify aesthetic tone with a named direction, demand audience and emotion context. Progressive layering — structure → type → color → motion → refinement. Source of this skill's order of operations. |

Supporting, on the positive side of the problem (what data-dense sports UI should be):

- [Designing the Modern Scorebug](https://www.sportsvideo.org/2026/06/09/designing-the-modern-scorebug-how-broadcast-graphics-teams-are-rethinking-the-most-important-element-on-screen/) — a dense scorebug functions as a live editorial dashboard; it must serve the casual and the diehard viewer at once.
- [Best Free Fonts for Sports & Athletics](https://fontalternatives.com/best-fonts-for/sports/) — condensed bold sans dominates because it maximizes letter size in constrained space; numerals matter as much as letters and need distinctly shaped, legible forms.
